# AI Rent Agreement Generator

## Overview

AI Rent Agreement Generator is an intelligent document automation system that uses a Large Language Model (LLM) to generate legally structured rental agreements from user-provided information. Instead of relying on fixed templates, the AI understands user inputs and creates professional, human-like agreements while maintaining proper legal formatting.

The generated agreements are automatically converted into PDF format and stored securely for future access.

## Key Features

* AI-powered rent agreement generation using an LLM
* Dynamic legal document creation
* Intelligent clause generation
* Automatic PDF generation
* FastAPI REST API
* MongoDB database integration
* Responsive frontend
* Agreement history management
* Secure environment variable configuration

## AI Workflow

1. User submits rental information.
2. FastAPI validates the input.
3. The LLM processes the information.
4. AI generates a complete legal rent agreement.
5. The agreement is stored in MongoDB.
6. A downloadable PDF is generated automatically.
